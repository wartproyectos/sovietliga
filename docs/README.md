# CÓMO USAR ESTOS ARCHIVOS EN CLAUDE CODE

## 📦 ARCHIVOS INCLUIDOS

1. **PROYECTO_LIGA_SOVIET.md** - Especificaciones completas del proyecto
2. **PROMPT_CLAUDE_CODE.md** - Prompt inicial para empezar en Claude Code
3. **estructura_google_sheets.png** - Captura de pantalla de la estructura de datos
4. **liga-soviet.html** - Versión básica de prueba (HTML standalone)

---

## 🚀 PASOS PARA CONTINUAR EN CLAUDE CODE

### Opción 1: Copiar y Pegar (Rápido)

1. Abre **Claude Code** en tu terminal
2. Crea una carpeta nueva para el proyecto:
   ```bash
   mkdir liga-soviet
   cd liga-soviet
   ```

3. Copia los archivos descargados a esta carpeta

4. Inicia Claude Code:
   ```bash
   claude
   ```

5. Copia y pega el contenido de **PROMPT_CLAUDE_CODE.md** en Claude Code

6. Claude Code leerá automáticamente el archivo **PROYECTO_LIGA_SOVIET.md**

---

### Opción 2: Usar como Referencia (Recomendado)

1. Descarga todos los archivos a tu computadora

2. Abre Claude Code y dile:
   ```
   Tengo 3 archivos con las especificaciones de un proyecto web. 
   Voy a compartirlos contigo:
   - PROYECTO_LIGA_SOVIET.md (especificaciones completas)
   - PROMPT_CLAUDE_CODE.md (prompt inicial)
   - estructura_google_sheets.png (captura de datos)
   
   Por favor léelos y confirma que entiendes el proyecto antes de empezar.
   ```

3. Adjunta los archivos cuando Claude Code te lo pida

4. Sigue las instrucciones que Claude Code te dé

---

## 📋 INFORMACIÓN ADICIONAL QUE NECESITARÁS

Cuando Claude Code te lo pida, prepara:

### 1. Enlace de Google Sheets
- El enlace al documento con los datos reales
- Asegúrate de que esté configurado para acceso público (al menos lectura)

### 2. Decisiones sobre el Generador de Equipos
Claude Code te preguntará sobre:
- ¿Hay información sobre nivel/skill de cada jugador?
- ¿Hay posiciones específicas (base, alero, pívot)?
- ¿Qué peso debe tener cada criterio de balanceo?

### 3. Preferencias de Diseño (Opcional)
- ¿Algún color específico además de rojo/amarillo?
- ¿Algún logo o imagen de la liga?
- ¿Preferencias de layout?
